# 这套界面是什么

本仓库是 KOReader 的修改版，只改了 Lua 前端，基于官方 v2026.07.1。设计参照了国内主流阅读 App 的交互，目标是在墨水屏上少层级、入口清楚、黑白分明。所有 KOReader 原有功能和设置都保留，原版菜单也在（换了样式）。

这一版**不含**任何第三方阅读服务的对接，只读设备上的本地书和 OPDS 书库。

## 主要改动

- **书架**：顶部「继续阅读」卡，一键回到上次的位置；封面网格；来源标签（本机 / OPDS 书库 / 全部）。长按书弹出操作单（继续阅读、标记读完、加入书单、书籍信息、删除、更多操作）。
- **阅读页**：页脚只留章节名、时间和页码。点屏幕中央呼出工具栏：顶栏是返回、书名、搜索、书签；底栏是目录、进度、亮度、字体、更多（原版菜单）。
- **面板**：
  - 进度：进度条、上一章 / 下一章、输入页码、阅读时长与预计剩余、自动翻页开关（长按改间隔）。
  - 亮度：灯光开关、夜间开关、十档亮度。Kindle 上关灯会同时关掉系统的自动亮度，避免灯自己亮回来。
  - 字体：字号、常用字体、行距、边距、首行缩进、段距，默认跟随原书；更细的在「更多排版设置」。
- **选中文字**：一行工具条（划线、写想法、复制、查词、搜索、更多）；中文按词选取，不用逐字拖。
- **跳转后返回**：从目录、搜索、链接或进度条跳走后，右下角出现「返回原进度」，翻几页后自动消失。
- **原版菜单与对话框**：页签改成图标加文字，开关、子菜单箭头、右侧取值统一样式；输入框、键盘、确认框统一圆角描边。
- 去掉了「在线更新」菜单，避免一键升级覆盖界面。

## 机型差异

界面按屏幕短边等比缩放，竖屏、横屏、不同分辨率都按同一套比例排版。KOReader 支持的 Kindle 都能装，下面是需要知道的差异：

- **带暖光的机型**（Oasis 2/3、Paperwhite Signature 等）：亮度面板在亮度条下面多一条色温（冷 ↔ 暖），没有暖光的机型不显示。
- **会自动旋转的机型**（Oasis 等）：横屏时控件按短边缩放，不会溢出屏幕。要固定方向，在原版菜单「设置 → 屏幕 → 旋转」里设。
- **有实体翻页键的机型**（Oasis、Voyage 的压感键等）：按键照 KOReader 原生行为翻页，界面没有改动。
- **大屏机型**（Scribe 等）：控件会按屏宽相应放大，排版比例与小屏一致。手写笔相关功能不在本界面范围内。
- **彩色屏**（Colorsoft）：界面本身是黑白的，书里的彩色插图照常显示。

实机长期使用过的是 Kindle Voyage（固件 5.13.6，kindlepw2 包）。其他机型遇到布局问题，请到仓库提 issue，附上机型、固件和截图（KOReader 截图手势：两指同时点屏幕对角）。

## 已知限制

- 只适配 KOReader v2026.07.1，别的版本会崩。
- 字体和词典不随界面附带，要自己放进 `koreader/fonts/`、`koreader/data/dict/`。
- 覆盖时不带 `--delete`，所以 Kindle 版 KOReader 自带的插件（SSH 等）会保留；界面自己的插件（chinese：中文按词选取）会加进去。
