# 这套界面是什么

本仓库是 KOReader 的修改版，只改了 Lua 前端，基于官方 v2026.07.1。设计参照了国内主流阅读 App 的交互，目标是在墨水屏上少层级、入口清楚、黑白分明。所有 KOReader 原有功能和设置都保留，原版菜单也在（换了样式）。

书库来源有三种：设备上的本地书、OPDS 书库，以及**微信读书**（随包附带开源插件 weread.koplugin，见下文）。

## 微信读书

- 插件：[finlater/weread.koplugin](https://github.com/finlater/weread.koplugin) v1.7.1，AGPL-3.0，原样随包放在 `koreader/plugins/weread.koplugin`（LICENSE、NOTICE 都在），本仓库不改插件文件，界面在运行时换皮。Kindle 上已经有这个插件（用户自己装过或插件自更新过）时，`ui_install.sh` 保留 Kindle 上的版本。
- 入口：书架右上角**第一个标签「微信读书」**。登录后，之后开机或关书都会落回上次停留的来源（默认微信读书）；切到「本机」后就落在本机书架。
- 页面：和本机书架同一个页头（「书架」+ 来源标签 + ⋯），顶部「继续阅读」卡、封面网格、翻页条都与本机一致；插件原顶栏的分组、公众号、搜索、排序、筛选、刷新，以及搜索微信读书、阅读统计、账号都收在 ⋯ 里。书籍详情、书评、阅读统计、章节目录、划线章节匹配这些整页，页头统一成「‹ 返回 | 标题」。
- 点按：书架上**单击直接读**——按云端进度打开对应章节（已下载直接开，没下载的只下这一章、下完即开）；从没下载过的书第一次点开，先弹提示单（开始阅读 / 下载全书 / 书籍详情）。**长按进书籍详情**。继续阅读卡同样直接读。关书后回到打开它的那个标签（从微信读书打开的回微信读书）。
- 书籍详情：封面、书名、作者、推荐值 · 点评数 · 字数、读到 x% · 已缓存章节；「阅读 / 继续阅读」「下载全书」两个主按钮；章节目录、书评、获取最新信息、清除缓存；简介点开看全文。
- 阅读：插件按章下载，每章是一个 EPUB，阅读页统一换成全书口径——顶栏显示书名，⋯ 里有书籍详情 / 全书目录 / 书评 / 下载全书 / 阅读统计；「目录」是全书目录（本章加粗、标已下载，点哪章开哪章）；进度面板的上一章 / 下一章跨章节；读到章末直接接下一章。
- 全书页码：没下载的章节排不了版，按字数估算。每页字数用已读过的章节累计算（只算 1000 字以上的章，累计到 2 万字后固定），所以换章时总页数不变；改了字号、行距、边距、字体会重新累计。刚开始读的前一两章总页数可能修正一次。
- **账号不随包**：包里只有插件代码，没有任何 Cookie、API Key 或阅读数据（打包自检会拦）。没登录时「微信读书」标签显示登录页，步骤是：手机微信读书「我 › 设置 › 微信读书 Skill › 获取 API Key」，然后在 Kindle 上点「扫码登录」，用微信扫码，在手机确认页**勾选「自动退出登录」**再确认（不勾的话手机显示成功、Kindle 却报 `getLoginInfo failed: HTTP 401`）。登录信息只写在 Kindle 的 `koreader/settings/weread.lua`。
- 需要联网：扫码、同步书架、下载章节、上报进度和时长都要开 Wi-Fi。平时保持飞行模式的，下载完章节就能离线读。
- 插件更详细的设置（下载、进度同步、时长上报、划线想法）在原版菜单「工具 › 微信读书」。

## 主要改动

- **书架**：顶部「继续阅读」卡，一键回到上次的位置；封面网格；来源标签（微信读书 / 本机 / OPDS 书库 / 全部）。长按书弹出操作单（继续阅读、标记读完、加入书单、书籍信息、删除、更多操作）。
- **阅读页**：页脚左边是章节名，右边是「⚡电量 时间 页码」，没有进度条（装上后会把设备上存过的旧页脚设置换成这套布局，只换一次，之后在菜单里改照常保存）。点屏幕中央呼出工具栏：顶栏是返回、书名、搜索、书签；底栏是目录、进度、亮度、字体、更多（原版菜单）。
- **面板**：
  - 进度：进度条、上一章 / 下一章、输入页码、阅读时长与预计剩余、自动翻页开关（长按改间隔）。
  - 亮度：灯光开关、夜间开关、十档亮度。Kindle 上关灯会同时关掉系统的自动亮度，避免灯自己亮回来。
  - 字体：字号、常用字体、行距、边距、首行缩进、段距，默认跟随原书；更细的在「更多排版设置」。
- **选中文字**：一行工具条（划线、写想法、复制、查词、搜索、更多）；中文按词选取，不用逐字拖。
- **跳转后返回**：从目录、搜索、链接或进度条跳走后，右下角出现「返回原进度」，翻几页后自动消失。
- **原版菜单与对话框**：页签改成图标加文字，开关、子菜单箭头、右侧取值统一样式；输入框、键盘、确认框统一圆角描边。
- 去掉了「在线更新」菜单，避免一键升级覆盖界面。

## 机型差异

界面按屏幕短边等比缩放，竖屏、横屏、不同分辨率都按同一套比例排版。KOReader 支持的 Kindle 都能装，下面是需要知道的差异：

- **带暖光的机型**（Oasis 2/3、Paperwhite Signature 等）：亮度面板在亮度条下面多一条色温（冷 ↔ 暖），没有暖光的机型不显示。
- **会自动旋转的机型**（Oasis 等）：横屏时控件按短边缩放，不会溢出屏幕。要固定方向，在原版菜单「设置 → 屏幕 → 旋转」里设。
- **有实体翻页键的机型**（Oasis、Voyage 的压感键等）：按键照 KOReader 原生行为翻页，界面没有改动。
- **大屏机型**（Scribe 等）：控件会按屏宽相应放大，排版比例与小屏一致。手写笔相关功能不在本界面范围内。
- **彩色屏**（Colorsoft）：界面本身是黑白的，书里的彩色插图照常显示。

实机长期使用过的是 Kindle Voyage（固件 5.13.6，kindlepw2 包）。其他机型遇到布局问题，请到仓库提 issue，附上机型、固件和截图（KOReader 截图手势：两指同时点屏幕对角）。

## 已知限制

- 只适配 KOReader v2026.07.1，别的版本会崩。
- 字体和词典不随界面附带，要自己放进 `koreader/fonts/`、`koreader/data/dict/`。
- 覆盖时不带 `--delete`，所以 Kindle 版 KOReader 自带的插件（SSH 等）会保留；界面自己的插件（chinese：中文按词选取）和微信读书插件（weread）会加进去。
